# Domains the link checker skips, each with all its subdomains.
#
# Read by scripts/check-links.sh into SKIP_DOMAIN_SUFFIXES. One domain per
# line, lower case, no scheme or path. A `#` starts a comment. At most 200
# entries: the checker stops with an error on more, on a duplicate, or on
# a line that is not a bare domain.
#
# These are well-known sites that refuse automated requests: bot
# management (Cloudflare, Akamai, DataDome), a login wall, or a
# consent or paywall redirect. They open in a browser and answer 403,
# 999 or a redirect loop to the checker. The list is limited to sites an
# EISS page is likely to cite: security studies publishers and
# repositories, think tanks, international-affairs media, EU and
# international institutions, and the travel and meeting sites used on
# conference pages. The same list is kept in the EISS site repository
# (EISSeuropa/EISSeuropa.github.io#2168), so a change to one goes to the
# other.
#
# Curated on 16 November 2026. Entries were not each probed
# from a GitHub runner. A link to a domain here is never checked, so a
# dead link on it goes unnoticed. To check a domain again, delete its
# line. Hosts and domains skipped for a reason seen in this repository's
# own CI, with their evidence, stay in SKIP_HOSTS and SKIP_DOMAIN_SUFFIXES
# in scripts/check-links.sh.
