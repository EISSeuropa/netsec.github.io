# Publishing news

NetSec news lives in one place, `data/news.json`, and feeds three surfaces:

- the **home page** "Latest News" block (the most recent items, capped at 4,
  decaying off after 18 months) — rendered by `assets/js/home-news.js`;
- the **`/news` archive** (the full chronological list, all three locales) —
  rendered by the same script's `renderNewsArchive`;
- the **RSS feed** at `/news.xml` — generated by `scripts/build-news-rss.py`.

There are two ways to add an item.

## 1. From a GitHub issue (the easy path)

Open an issue, write the news, and add the **`news`** label. The
`news-publish.yml` workflow then:

1. runs `scripts/publish-news.py` to prepend the item to `data/news.json`;
2. regenerates `news.xml`;
3. opens a PR on `news-publish/issue-<n>` that `Closes` the issue, with
   auto-merge armed (branch protection still gates it).

### Issue format

The issue **title** becomes the headline. The **body** becomes the excerpt,
with optional header lines at the very top (any order, case-insensitive):

```
Type: Announcement
WG: 3
URL: https://example.org/more
Date: 2026-06-20

The first paragraph here is the excerpt shown on the card. Keep it to a
sentence or two; the home card and the archive both show this text.
```

- **`Type:`** — a category tag shown as a small pill beside the date
  (`Event`, `Publication`, `Announcement`). Any other word still renders,
  Title-cased. The three standard ones are translated on the FR / DE pages.
- **`WG:`** — a Working-Group activity tag (`1`–`4`), rendered as a
  WG-coloured pill (e.g. `WG3`). Out-of-range values are ignored.
- **`URL:`** — adds a "Read more" call-to-action (opens in a new tab).
- **`Date:`** — ISO `YYYY-MM-DD`. Defaults to today. The archive groups
  items under a year heading from this date.

Only the first paragraph after the headers is used; anything below it is
ignored, so you can keep notes in the issue.

### Translations

Issue-published items are **English only**. The home and archive renderers
fall back to EN for FR and DE, so the item is visible immediately. To add a
hand translation (no machine translation, CLAUDE.md §1), edit the item in
`data/news.json` and give `title`, `body`, `displayDate`, and any CTA label a
`fr` / `de` key alongside `en`, exactly like the seeded items.

## 2. By hand

Edit `data/news.json` directly (full per-locale items), then run
`python3 scripts/build-news-rss.py` and commit both files. The
`news-drift.yml` CI gate fails if `news.xml` does not match `news.json`.

## Schema (per item)

| field | required | notes |
| --- | --- | --- |
| `id` | yes | stable slug; the archive anchors at `#news-<id>` |
| `pubDate` | yes | ISO datetime; drives sort order and decay |
| `title` | yes | `{en, fr?, de?}` |
| `body` | yes | `{en, fr?, de?}` |
| `displayDate` | yes | `{en, fr?, de?}` — the date pill text |
| `cta` | no | `{href, external, i18n:{en, fr?, de?}}`; `href` may be a string or per-locale map |
| `_source_issue` | no | set by the publisher; lets a re-labelled issue update its item |
